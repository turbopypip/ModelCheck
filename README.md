# ModelCheck

**Производитель действительно выпускал такую версию?**

По ссылке из карточки сервис ищет конкретную версию товара в документации производителя. Покупатель видит, удалось ли подтвердить модель и комплектацию, какие детали описания противоречат источнику или каких сведений пока не хватает. Вторую ссылку можно добавить для сравнения модели, комплектации и цены. Первый релиз охватывает мониторы и наушники на Ozon и DNS.

## Команда и ответственность

Индивидуальный проект. Кочкин Денис Сергеевич отвечает за проверку потребности покупателей, требования и сдачу контрольных точек. Его инженерный результат — сквозная проверка предложения от извлечения карточки до отчёта с источниками, сравнение предложений, тесты и поставка сервиса. Задачи, оценки и ожидаемые доказательства приведены в [плане работ](backlog.md).
